# Task Generator in Terminal / Gerador de Tarefas no Terminal

## 📌 Description (English)
This is a simple **Node.js** project that allows you to add tasks directly from the terminal.  
Each task has a priority (high, medium, or low) and is displayed with different colors using **ANSI codes**:
- Red → high priority  
- Yellow → medium priority  
- Green → low priority  

It’s a great first project to practice:
- Input and output handling in the terminal
- Array and object manipulation in JavaScript
- Using ANSI codes to style text

---

## 📌 Descrição (Português)
Este é um projeto simples em **Node.js** que permite adicionar tarefas diretamente pelo terminal.  
Cada tarefa recebe uma prioridade (alta, média ou baixa) e é exibida com cores diferentes usando **códigos ANSI**:
- Vermelho → prioridade alta  
- Amarelo → prioridade média  
- Verde → prioridade baixa  

É um ótimo primeiro projeto para praticar:
- Entrada e saída de dados no terminal
- Manipulação de arrays e objetos em JavaScript
- Uso de códigos ANSI para estilizar texto
